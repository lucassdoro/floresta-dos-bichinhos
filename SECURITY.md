# Segurança

O jogo roda offline e não coleta dados, mas problemas de segurança podem existir (por
exemplo, no carregamento de arquivos de progresso).

## Como relatar

**Não abra uma issue pública.** Use o relato privado do GitHub:
aba **Security** → **Report a vulnerability** neste repositório.

Inclua os passos para reproduzir, a versão do jogo e a plataforma. A resposta inicial vem em
até 7 dias.
